# Delta anomaly renderer notes

## 目的
CVDの累積値そのものではなく、各ローソク足ごとの `ΔCVD` を使って異常値を見つけやすくする。
巨大市場の絶対サイズで小さい市場が潰れないよう、各市場ごとに robust z-score 正規化して表示する。

## 変更点
- CVDパネルを累積ライン表示からヒートマップ表示へ変更。
- 値は `delta_quote` を優先し、なければ `delta`、それもなければ `cvd_quote/cvd` の差分で代替。
- 各市場ごとに `median` と `MAD` を使った robust z-score を計算。
- 表示は `±5` でクリップ。
- 赤系: 通常より大きい買い方向の ΔCVD。
- 青系: 通常より大きい売り方向の ΔCVD。
- 白付近: その市場の普段の変動範囲。

## 読み方
- 横軸: 時間。
- 縦軸: 市場。
- 同じ時刻に複数市場で赤/青が揃う場合は、全体フローの同期。
- 1市場だけ強く出る場合は、その市場固有の異常フロー候補。
- BTC価格が動かないのに強い色が出る場合は、吸収/仕込み/解消の候補として見る。

## 注意
- z-scoreは「その市場の過去窓内での異常度」なので、市場間の絶対出来高比較ではない。
- 窓内のデータが極端に少ない場合、異常度の安定性は落ちる。
- 継続的な片方向フローは、累積CVDの方が見やすい場面もある。
